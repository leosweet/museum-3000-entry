## What it does

`main.py` writes one line to `/output/entry.txt`: the museum label a museum
in the year 3000 puts beside an ordinary object from today — a smoke alarm,
misread by the future as a small white bird that screamed whenever its humans
attempted to cook.

The program is fully deterministic: no network, no randomness, no clock.
Every run writes byte-for-byte identical output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
